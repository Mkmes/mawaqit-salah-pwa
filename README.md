# mawaqit-salah-pwa

Compiled, silent Prayer Times PWA for iPhone and iPad.
Private application source and Android packages are not included.

Open https://mkmes.github.io/mawaqit-salah-pwa/ in Safari, then use
Share → Add to Home Screen.

This version requires an internet connection. Older offline workers are
retired without clearing saved application settings. The regional schedules
include «مواقيت الصلاة لقرية تل علي» and
«مواقيت الصلاة لناحية الزاب وضواحيها».

Choose the desired region in Settings and save your selection.
GitHub Actions verifies the compiled release before deploying GitHub Pages.
